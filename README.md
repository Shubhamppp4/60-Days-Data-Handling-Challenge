# 60 Days of Data Handling Challenge 🚀

## About This Challenge

This is my 60-day hands-on challenge to develop strong real-world data handling skills for Data Science and Machine Learning.

My goal is to become confident in handling different types of datasets, from small datasets to large-scale data.

## Goals

- Data collection from multiple sources
- Data exploration and profiling
- Data cleaning and preprocessing
- Handling missing values and outliers
- Data type conversion and validation
- Feature engineering
- Feature selection
- Encoding categorical variables
- Scaling and transformation
- Handling large datasets efficiently
- Working with CSV, Excel, JSON, APIs and databases
- Building ML-ready data pipelines
